## `Rect`

A `Rect` is a table that represents a rectangle. It has the following fields:

* `x` — the x coordinate of the rectangle's top-left corner.
* `y` — the y coordinate of the rectangle's top-left corner.
* `w` — the width of the rectangle.
* `h` — the height of the rectangle.

It also has the following methods:

### `Rect:contains(x, y)`

Returns `true` if the rectangle contains the point `(x, y)`, and `false` otherwise.

### `Rect:isHovered()`

Returns `true` if the mouse is hovering over the rectangle, and `false` otherwise.

### `Rect:isClicked()`

Returns `true` if the mouse is clicked on the rectangle, and `false` otherwise.
